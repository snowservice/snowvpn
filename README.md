## 🚀 Быстрый старт (Windows) / Quick Start (Windows)

**RU**
1. Скачай и запусти установщик по кнопке выше (либо возьми portable-версию в том же релизе, если не хочешь ставить).
2. Открой вкладку **«Подписки»** и вставь ссылку на подписку (или добавь ключ через бота), нажми **«Добавить и применить»**.
3. На главном экране выбери сервер и нажми **«Подключить»**.
4. Режим по умолчанию — **TUN** (весь трафик через VPN, самый простой и надёжный вариант). Если нужно, чтобы через VPN шли только отдельные приложения — переключись на вкладке **«Правила»** в режим **«По приложениям»** и настрой их там.

**EN**
1. Download and run the installer above (or grab the portable build from the same release if you don't want to install).
2. Open the **«Subscriptions»** tab, paste your subscription link (or add a key via the bot), press **«Add and apply»**.
3. On the home screen pick a server and press **«Connect»**.
4. Default mode is **TUN** (all system traffic goes through VPN — the simplest, most reliable option). If you only want specific apps routed through VPN, switch to **«Per-app»** mode on the **«Rules»** tab and configure them there.
